# Healthcare Data Analytics

An end-to-end healthcare analytics project that uses **Excel**, **Power BI**, and **Tableau** to analyze hospital data and uncover insights on patient volume, treatment costs, and healthcare outcomes.

---

## Project Objective

Help hospital administrators and healthcare decision-makers answer questions such as:

- How many patients are admitted, and how does volume change over time?
- Which medical conditions and departments have the highest patient counts?
- What are the billing and treatment costs across conditions, age groups, and insurance providers?
- How long do patients stay in the hospital, and what factors affect it?

## Approach

1. **Data Cleaning (Excel):** Removed duplicates, handled missing values, fixed data types, and created calculated columns such as age groups and length of stay.
2. **Analysis (Excel):** Built pivot tables to summarize patients, billing, and conditions.
3. **Visualization (Power BI and Tableau):** Designed interactive dashboards with KPI cards, charts, and filters.
4. **Insights:** Summarized the main findings for decision-makers.
